TOPTRO X9 — owner tools

This page runs on your projector's own browser and talks to the device's local factory service (ws://127.0.0.1:7681, loopback only). Nothing leaves your LAN. Only use this on hardware you own.

1. Run the USB-stick launcher

Prerequisite: a FAT32 stick prepared per the repo's exploit/README.md (MScript.sh, dropbear, your authorized_keys), inserted in the powered-on projector.

2. Log

Troubleshooting

WebSocket to 127.0.0.1 was refused by the browser (mixed-content). Serve this page over plain HTTP instead: run python3 tools/x9-cdp-shell.py on any LAN machine and open http://<that-host>:8089/ here.
